# Codist Workshop

Materials for a hands-on workshop on Ship a Next.js App with Claude Code

## What’s here

- **[prompts.md](./prompts.md)** — Exercise prompts in order: landing pages, architecture rules, task views with mock data, database migration with Prisma, bug fixes, Shadcn components, Plan Mode for new tasks, and optional Claude Code /design workflows.
- **[ship-a-next.js-app-with-claude-code.pdf](./ship-a-nextjs-app-with-claude-code.pdf)** — Slides / reference for the “Ship a Next.js App with Claude Code” session.
- **`images/`** — Reference screenshots (e.g. Todoist-style landing, Codist landing, Today view).

The companion app you build in the workshop is a **To-Do product named Codist** (today/inbox routes, due dates, checkboxes, seed data, and Prisma-backed persistence).

## Workshop application (code)

The **starter Next.js app** you update during the workshop lives in a separate repository:

- **[github.com/mauricedb/codist](https://github.com/mauricedb/codist)** — clone this and work against `main` (or the default branch) while following the prompts here.

For a **completed reference** after the exercises, use the same repo on the **`building-the-app`** branch.

## How to use this repo

1. Clone **[codist](https://github.com/mauricedb/codist)** and run installs / dev server from that project when prompts mention the app.
2. Open **Prompts.md** and work through the sections in sequence, or jump to the topic you need (rules, Prisma seed/studio, Design).
3. Use the PDF alongside for framing and extra context.
